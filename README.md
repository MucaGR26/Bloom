# Bloom

Projeto Angular com API Spring Boot.

## Front-end
Na pasta raiz do projeto:

```bash
npm install
npm start
```

Acesse http://localhost:4200.

## Back-end
Em outro terminal, na pasta raiz (precisa do Java 21 ou mais novo):

```bash
npm run backend
```

A API fica em http://localhost:3000. Verificação: http://localhost:3000/api/health.

Os dados locais de usuários ficam em `backend/data/users.json`. Mais detalhes em `BACKEND-README.md`.
